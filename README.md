# Local Assistant

Local Assistant — настольное приложение на C++ и Qt для работы с документами и мониторинга состояния компьютера. Приложение использует локальные языковые модели для формирования ответов, RAG для поиска информации в документах и MCP для получения системных показателей.

Цель проекта — предоставить единый интерфейс для запросов к документам и данным компьютера с отображением источников ответа. Проект находится в активной разработке.

## Что уже работает

- Интерфейс чата с несколькими диалогами и переключением между ними.
- Загрузка TXT и PDF с текстовым слоем, проверка дубликатов и отображение состояния индексации.
- Асинхронное извлечение текста из PDF через Poppler (`pdftotext`), с обработкой ошибок и таймаутом.
- Разбиение текста на чанки, получение embeddings и поиск подходящих фрагментов для ответа.
- Генерация ответов через локальный сервер LM Studio.
- Получение загрузки CPU и RAM через собственный MCP-сервер на Python.
- Отображение источников ответа и тёмная тема интерфейса.

Пока чаты и индекс хранятся в памяти и не сохраняются между запусками. TXT читаются в UTF-8; текст из PDF также извлекается в UTF-8. OCR не реализован: сканы без текстового слоя не поддерживаются. DOC и DOCX пока не поддерживаются.

Размер исходного файла ограничен 1 МиБ для обоих форматов. На извлечение текста из PDF отводится 30 секунд. Одновременно обрабатывается один PDF; повторный запрос во время извлечения отклоняется. После чтения PDF проходит ту же очередь индексации и поиска, что и TXT.

## Стек

C++17, Qt 5 Widgets и Network, CMake. Для чтения PDF — утилита Poppler `pdftotext`, запускаемая через `QProcess`. Для MCP-сервера — Python, MCP SDK и psutil. Сейчас использую EmbeddingGemma для поиска по документам и Qwen3-14B для генерации ответов.

## Структура исходников

- `include/` — заголовки `.h` и `.hpp`.
- `src/` — реализации `.cpp` и точка входа `main.cpp`; форма окна остаётся в `src/ui/`.
- В обеих папках сохраняется разделение на `application`, `chat`, `documents`, `io`, `llm`, `mcp`, `rag` и `ui`.
- Например, объявление загрузчика находится в `include/io/document_loader.hpp`, реализация — в `src/io/document_loader.cpp`.

Новые заголовки и реализации нужно добавлять в `CMakeLists.txt`. Основной способ сборки — CMake; `IndustrialAiAssistant.pro` содержит альтернативный проект qmake.

Чтение документов разделено на обработчики с общим интерфейсом `IDocumentReader`. `DocumentLoader` выбирает `TxtDocumentReader` или `PdfDocumentReader` по расширению файла и передаёт результат сигналом `documentReady`. PDF-reader использует `PdfTextExtractor` для управления процессом и таймером. `DocumentManager` добавляет готовый документ в библиотеку, а `AssistantService` запускает индексацию.

## Запуск

1. Открыть `CMakeLists.txt` в Qt Creator и выбрать комплект Qt 5 с компилятором, поддерживающим C++17.
2. В LM Studio подготовить модели `text-embedding-embeddinggemma-300m-qat` и `qwen/qwen3-14b`, запустить локальный API на порту `1234`.
3. Из корня проекта создать окружение Python и установить зависимости:

   ```powershell
   python -m venv mcp_server/.venv
   ./mcp_server/.venv/Scripts/python.exe -m pip install -r mcp_server/requirements.txt psutil
   ```

4. Проверить пути к Python и `server.py` в `src/mcp/mcp_client.cpp`: сейчас они заданы под мою папку `C:/Qt/IndustrialAiAssistant`.
5. Для PDF распаковать комплект Poppler для Windows вместе с DLL и остальными файлами, сохранив структуру каталогов. Проверить `pdfExtractorPath` в `src/application/assistant_service.cpp`: сейчас это `C:/Qt/IndustrialAiAssistant/tools/poppler-26.09.0/Library/bin/pdftotext.exe`. Если комплект находится в другом месте, изменить этот путь. Добавлять Poppler в глобальный PATH не требуется.
6. Собрать и запустить приложение. MCP-сервер запускается из приложения автоматически; `pdftotext` запускается при загрузке PDF.

## Проверка PDF

В корне проекта находится `test-document.pdf` — небольшой документ с русским текстом и вымышленными данными. Загрузить его через кнопку добавления документа, дождаться статуса «Готов» и спросить: «Сколько датчиков установлено в проекте “Северный маяк”?». Ожидаемый ответ — 12. В источниках должны отображаться фрагменты этого PDF.

Дополнительно можно проверить повторную загрузку того же документа, PDF без извлекаемого текста и загрузку обычного TXT. Ошибка чтения не должна мешать следующей попытке. Позиции источников пока обозначают смещения в извлечённом тексте, а не номера страниц PDF.
